# v1.1.0 验证记录

本版替换媒体组件后，完成以下检查：

- Go 格式检查、go vet、完整单元测试与 Windows 竞态检查通过。
- 使用合成音频完成 12 次转换，覆盖 FLAC、WAV、Vorbis、AAC、Opus、WMA 和 MP3。
- 实际 8 / 16 / 24 / 32 位 FLAC 均通过全部 PCM MD5 和样本数核对。
- 既有加密 FLAC、错误密钥、连续 musicex 尾部与损坏音频回归测试通过。
- 重复运行跳过已有输出，原始输入与已有输出内容保持不变。
- GUI 自检完成两首合成音频，Logo、窗口缩放、最大化和 100% 进度检查通过。
- 两个媒体 EXE 的 PE 依赖只含 Windows 系统 DLL。
- 固定源码、工具链档案和构建补丁均通过 SHA-256 核对。

合成样本与本机测试目录不作为真实音乐或私人报告上传。
发行包带经过整理的验证摘要与实际二进制哈希；这些检查不保证未来客户端版本或未知格式兼容。
